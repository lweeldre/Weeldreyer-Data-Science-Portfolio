# Basic Streamlit App – Penguin Analytics 🐧📊

## Project Overview

This project is an interactive data exploration web application built using Python and Streamlit. It serves as my foundational portfolio project for learning how to transform static datasets into interactive dashboards using Python-based web tools.

Using the Palmer Penguins dataset, this application allows users to explore penguin species data through interactive tables, dropdown menus, sidebar filters, scatterplots, bar charts, and summary metrics.

This project demonstrates early skills in:
- Streamlit dashboard development  
- Data visualization  
- Interactive filtering  
- Basic exploratory data analysis (EDA)  
- User interface design with Python  

It established the groundwork for later portfolio projects involving more advanced machine learning and deployment.

## App Features

# Dataset Overview

- Loads and displays the Palmer Penguins dataset
- Presents raw data in interactive tables
- Introduces users to species-specific biological measurements

---

# Species-Specific Filtering

### Dropdown Selection:
- Users can select individual penguin species
- Displays filtered statistics for selected species

### Sidebar Multi-Select:
- Users can compare multiple penguin species simultaneously
- Provides broader exploratory flexibility

---

# Summary Metrics

The app dynamically calculates:

- Total Penguins
- Average Body Mass (g)
- Average Bill Length (mm)

These metrics update automatically based on user-selected filters.

---

# Interactive Visualizations

## Scatter Plot Analysis
Users can:
- Select custom X and Y axes
- Compare:
  - Bill Length
  - Bill Depth
  - Flipper Length
  - Body Mass

### Purpose:
This helps users observe biological correlations and species clustering patterns.

---

## Population Distribution Bar Charts

### Penguins per Island:
- Compares species populations across islands

### Average Body Mass:
- Displays average body mass by species
- Includes optional raw data toggle
