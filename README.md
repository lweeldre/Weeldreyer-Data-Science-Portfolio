This project highlights foundational skills in:

## [Portfolio Update 3](https://github.com/lweeldre/Weeldreyer-Data-Science-Portfolio/tree/main/MLStreamlitApp)

- This project is an interactive machine learning web application built using Python and Streamlit. It allows users to explore supervised learning models in a hands-on environment.

Features:
- Upload custom datasets or use built-in sample datasets (Penguins, Iris, Breast Cancer)
- Select a target variable for prediction
- Train multiple supervised machine learning models:
  - Logistic Regression
  - Decision Tree
  - K-Nearest Neighbors (KNN)
- Adjust hyperparameters interactively using sliders
- Evaluate model performance using:
  - Accuracy
  - Precision, Recall, and F1-score
  - Confusion Matrix
  - ROC Curve (supports both binary and multiclass classification)

### Technical Highlights:
- Automatic handling of missing data
- Feature encoding using one-hot encoding
- Real-time model training and evaluation
- Multiclass ROC curve implementation using a one-vs-rest approach

### Significance:

This project builds on earlier portfolio work by introducing machine learning and model evaluation, while also expanding into **interactive application development and deployment**.

It demonstrates the ability to:
- Apply machine learning models to real datasets
- Interpret model performance using multiple metrics
- Build user-friendly interfaces for data science tools
- Deploy applications for public use using Streamlit Cloud
